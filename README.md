# PULSE Projects — Android build workspace

Acest repository conține codul aplicației PULSE Projects, creat pentru gestionarea proiectelor, deadline-urilor și notificărilor Android.

Aplicația nu include date personale sau lista proiectelor utilizatorului. Datele sunt stocate local pe telefon.

Build-ul aplicației este disponibil în branch-ul `pulse-android14-build`, prin GitHub Actions.
